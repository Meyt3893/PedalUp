# PedalUp 🚴

A Hebrew practice game for kids: maths and an English bike trail with daily missions.
Sign up with a username, password and the child's name; progress saves itself to the account.

`config.js` holds the Supabase project address and its **publishable** key (never a secret key).

`admin.html` is the admin page (who uses the site, classes). It works only for an account marked as admin in the database.
